# SAP S/4HANA Cost Center Controlling Project

### Budget Monitoring, Actual Cost Analysis & Budget Availability Control

## 1. Project Overview

This project demonstrates a simulated SAP S/4HANA Controlling (CO) scenario for ABC Manufacturing GmbH.

The project focuses on departmental cost center management, budget monitoring, actual cost analysis, open commitments, budget adjustments and Budget Availability Control (BAC).

Microsoft Excel was used for financial calculations and analysis, while Microsoft Power BI was used to develop an interactive management dashboard.

## 2. Project Objectives

* Analyse departmental cost center budgets.
* Monitor actual costs and open commitments.
* Calculate available budgets and budget utilization.
* Evaluate budget supplements, returns and transfers.
* Analyse Budget Availability Control (BAC) status.
* Develop a Power BI dashboard for financial monitoring.
* Identify departments requiring management attention.
